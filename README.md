# Ciberseguridad: guía básica
Bienvenido a este proyecto sobre **ciberseguridad**. Aquí encontrarás, explicado de forma sencilla, qué esla ciberseguridad, de qué nos protegemos y cómo hacerlo.  

## ¿De qué trata?
La ciberseguridad protege **personas, sistemas y datos** frente a los ciberataques. En esta web verás los conceptos fundamentales, los tipos de malware y hackers, un **ataque real** (WannaCry, 2017) y una lista de **hábitos** para protegerte.
